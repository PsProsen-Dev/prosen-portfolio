**Status: in design / build. No live trading.**

An AI trading intelligence stack built around a paper-trade-safe Python bot:

- Order execution through the Shoonya (Finvasia) API — zero brokerage, free API access
- P&L dashboard for reviewing paper-trade performance before risking a rupee
- Pine Script → webhook → automation pipeline (in design)

Signals under exploration: MACD and Bollinger Bands. Backtesting runs through GitHub Actions.

The rule this project is built on: the bot earns the right to trade real money only after the paper record says it should.
